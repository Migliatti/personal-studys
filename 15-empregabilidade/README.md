# 15-empregabilidade

**Alvo:** Ambos
**Pré-requisito:** `14-etl-integracoes-documentacao`
**Tempo estimado:** 3 semanas a 8h/semana

## Objetivo

Apresentar experiência transferível de suporte e demonstrar domínio técnico em entrevista.

## Conteúdo

- Currículo de uma página baseado em evidências.
- README orientado a problema, operação e trade-offs.
- Explicação de arquitetura e debugging narrado.
- HTTP, TypeScript, SQL, testes, transações, autenticação, Docker e Git.
- Webhooks, mapping, retry, idempotência e reconciliação.
- Histórias STAR para incidente, SLA, implantação e cliente.
- Busca equilibrada para as duas vagas-alvo.

## Entregável no repo

- `curriculo-master.md` e `banco-de-historias-star.md`.
- `perguntas-tecnicas.md` com respostas próprias.
- Três apresentações arquiteturais cronometradas.
- Checklist dos projetos e tracker simples de candidaturas.
- IA aceitável: revisão gramatical após texto autoral.
- IA proibida: inventar experiência, responder tecnicamente ou preparar debugging.

## Projeto-portfólio

Revisar os três repos existentes; não criar um quarto projeto.

## Critério de verificação binário

Em 60 minutos sem consulta: apresentar um projeto, modelar uma integração, escrever um `JOIN`, diagnosticar um `500`, explicar idempotência/retry e alterar uma regra mantendo testes verdes.

## Checklist

- [ ] Currículo possui apenas experiências verdadeiras.
- [ ] Três projetos são demonstráveis em cinco minutos cada.
- [ ] Simulação técnica de 60 minutos concluída.
- [ ] README raiz contém os links finais.
