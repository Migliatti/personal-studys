# 00 — Revisão de lógica e fundamentos de JavaScript

**Alvo:** Ambos
**Pré-requisito:** contato anterior com lógica de programação; não exige fluência em Python ou JavaScript.
**Tempo estimado:** 6 semanas a 8h/semana (48 horas).
**Status:** Não iniciado.

## Objetivo

Escrever, explicar, modificar e investigar programas pequenos em JavaScript com autonomia suficiente para começar o módulo de HTTP.

Este módulo considera seu relato: você já estudou lógica, fez programas pequenos em Python e está há algum tempo sem programar. Isso é um ponto de partida, não uma comprovação de domínio. As atividades vão mostrar o que precisa de revisão.

Abra a **sessão 1** do [guia de estudo](./guia-de-estudo.md). Você vai executar um arquivo pequeno antes de avançar para decisões, repetições e funções.

## Conteúdo

- Algoritmo, entrada, processamento e saída; traduzir uma ideia para instruções.
- Executar arquivos com Node.js; distinguir linguagem de ambiente de execução.
- Valores, tipos básicos, variáveis, operadores, strings e conversões.
- Comparações, booleanos, condições e repetições.
- Funções, parâmetros, retorno e escopo.
- Arrays, objetos, acesso e alteração de dados.
- JSON, módulos e reconhecimento de callbacks.
- Leitura de erros e investigação orientada por hipóteses.

Node.js será usado desde o começo apenas para executar JavaScript no terminal. Não é necessário aprender HTML, DOM, frameworks, banco de dados ou TypeScript neste módulo. Promises, event loop e `async/await` serão aprofundados no módulo 03; aqui basta uma introdução à diferença entre chamar uma função e entregá-la para outra operação chamar.

## Ritmo e progressão

Quatro sessões de duas horas por semana. Nas primeiras quatro semanas, reserve duas horas para teoria aplicada, duas para exercícios, três para prática incremental e uma para revisão e registros. Nas semanas 5–6, a prática incremental dá lugar à POC e à verificação final.

O prazo é uma estimativa, não um limite para aprender. Se a leitura foi fácil, mas você não consegue escrever ou explicar, continue praticando antes de avançar. Ao ampliar o módulo, desloque também o cronograma da trilha.

## Uso de IA

Valem as [regras do repositório](../docs/regras-de-uso-de-ia.md) e a [tutoria](../AGENTS.md).

Durante a prática, apresente sua tentativa para receber uma pista de cada vez. Setup e dúvidas gerais de sintaxe podem receber ajuda direta. O raciocínio, a organização do programa, a escolha das verificações e as alterações são seus.

A IA não escreve os programas, corrige os arquivos avaliados nem fornece resultados esperados. O exercício 17 e a verificação final têm restrições próprias de consulta e IA. A revisão desses momentos acontece somente após você declarar a tentativa encerrada.
